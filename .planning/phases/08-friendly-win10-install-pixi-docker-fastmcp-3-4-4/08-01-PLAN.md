<objective>
Create `scripts/install_matlab_engine.py` — the single source of truth for MATLAB engine
acquisition (D-01). It detects the installed MATLAB release, maps it to the matching PyPI
`matlabengine==<maj>.<min>.*` version, and pip-installs it; it falls back to the local
`extern/engines/python` build when PyPI is unreachable or `MATLAB_MCP_VENDOR` is set.

Purpose: `matlabengine` is sdist-only and its build RAISES if a matching MATLAB is not
installed, so it can NEVER be a static dependency (that would break `pip install` / `pixi
install` / CI on any host without that exact MATLAB). Installing it from a shared script,
called by both the pixi `install-engine` task (08-05) and the slimmed `install.bat` (08-04),
is the pivot of this whole phase.

Output: `scripts/install_matlab_engine.py` + `tests/test_install_matlab_engine.py`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| environment -> pip spec | MATLAB_RELEASE env var / Windows registry value / directory names cross into a `matlabengine==...` pip install command |
| PyPI / vendor -> local env | a downloaded or vendored matlabengine sdist is built and installed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01-INJ | Tampering / Elevation | resolve_engine_spec | high | mitigate | Whitelist the resolved token against RELEASE_TO_ENGINE before interpolating; raise ValueError on any unknown value so a spoofed MATLAB_RELEASE or registry entry cannot inject an arbitrary pip spec / command. Covered by the unknown-token unit test. |
| T-08-01-REG | Information disclosure | detect_release (winreg/glob) | low | accept | Only reads non-admin MathWorks registry subkeys and standard install globs; no secrets read or logged. |
| T-08-01-SC | Tampering (supply chain) | matlabengine install | medium | mitigate | matlabengine is MathWorks' official PyPI package (RESEARCH §1: sdist-only, BSD-3-Clause-style license, provenance verified). Pin to `<maj>.<min>.*` matched to the detected release; offline path installs only the vendored/local MathWorks tree. Not an [ASSUMED]/[SUS] package — no blocking checkpoint required. |
